# Fully pinned dependency set for reproducible PyInstaller builds.
#
# Generated from a verified working environment (Windows, Python 3.14,
# 2026-08). The build workflow installs the torch stack FIRST -- one flavor
# per artifact -- then this file, so pip never resolves torch itself:
#
#   CPU leg:   pip install torch==2.13.0 torchvision==0.28.0
#   CUDA leg:  pip install torch==2.13.0+cu126 torchvision==0.28.0+cu126 \
#                  --index-url https://download.pytorch.org/whl/cu126
#
# +cu126 is the newest CUDA-12 wheel line; through CUDA minor-version
# compatibility it runs on any NVIDIA driver >= 527.41. (Newer still is
# +cu130, but that jumps to the CUDA-13 driver floor ~580.xx and would lock
# out most of the fleet this app targets.)
#
# torch/torchvision are deliberately absent below for exactly that reason.
#
# Both opencv variants appear because each has a hard requirer we need:
# ultralytics demands plain opencv-python, easyocr demands -headless (and
# -headless does not satisfy ultralytics' requirement -- no Provides: marker).
# They install into the same cv2/ directory; pinning both to one version
# keeps whichever lands last deterministic instead of version-skewed.
